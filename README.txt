COE421 Lab 10 Exercise 1 - Observer Pattern

IMPORT
File > Import > General > Existing Projects into Workspace > Next.
Select archive file > Browse > select COE421_Lab10_Exercise1.zip.
Tick COE421_Lab10_Exercise1 > Finish.
You may also extract the ZIP, then choose Select root directory and
browse to the extracted project folder.

RUN
Expand the project > src > (default package).
Right-click Driver.java > Run As > Java Application.
The first transformation appears after 5 to 10 seconds.
The program runs for approximately 2.5 to 3.5 minutes until energy is 0.
To stop early, click the red Terminate button in the Console.

SOURCE
Driver, Observer, Subject, UI, Eren, Friend and Titan are transcribed
from pages 4-7 of the supplied Lab 9 PDF, with page numbers removed.
The PDF does not include the TeamLeader class listing. TeamLeader.java
has therefore been added to implement the exercise requirements and
allow the supplied Driver to compile. The other class code is unchanged.
No external libraries are required. Use a Java 11 or newer runtime.
